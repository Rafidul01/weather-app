# 🌤 Weather App

A responsive weather search application built with **React**, **Redux Toolkit**, **RTK Query**, and **Tailwind CSS**. Users can search for real-time weather by city, toggle between light and dark modes, and revisit previous searches easily.

🔗 **Live Preview:** [Click here to view](https://digidenweatherapp.netlify.app)  

---

## 🚀 Features

- 🌐 Search weather by city (via OpenWeather API)
- ⚡ Fast and reactive UI using **RTK Query**
- 🧠 State management with **Redux Toolkit**
- 💡 Clickable recent search history
- 🌙 Dark mode toggle (persists via localStorage)
- 🎨 Stylish, responsive UI with Tailwind CSS
- 🧪 Built with **Vite** for lightning-fast development

---

## 🛠️ Tech Stack

- **React + TypeScript**
- **Redux Toolkit**
- **RTK Query**
- **Tailwind CSS**
- **Vite**
- **OpenWeatherMap API**

## 🧪 Installation Process

### 1. Clone the repository

```bash
git clone https://github.com/your-username/weather-search-app.git
cd weather-search-app
npm install
npm run dev
```
### 2. In .env file add
VITE_OPENWEATHER_API_KEY=your_api_key_here
